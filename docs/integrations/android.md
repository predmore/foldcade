# Android games and apps

Foldcade automatically finds installed apps with launcher icons. Games start in **Android Games**, other apps in **Android Apps**, and recognized emulators and streaming apps in **Emulators**.

## Add a game

1. Install the game and return to Foldcade.
2. Find it in **Android Games**, **Android Apps**, or **All**. The L1 drawer also opens the Games and Apps lists.
3. Press **A** to open it on the top screen or **X** on the bottom.

Android decides whether an app is a game. Use **Y › Move to** to change a tile's folder.

Empty default folders are hidden. If Android Games is absent, check Android Apps and All.

## Arrange your apps

Press **Y** to move tiles, create folders, or **Remove from Home**. Removed tiles stay in All; **Y › Add to Home** restores them without reinstalling the app.

Check [New games on Home](README.md#a-game-is-in-all-but-missing-from-home) if new apps appear only in All.

An emulator's tile opens the app. Add its games through [local folders](local-games.md), [RomM](romm.md), or the relevant [source guide](README.md).

## Updates and saves

The list updates at startup, when you return, and when apps are installed, removed, or changed. Apps without launcher icons do not become tiles.

Each app handles its own saves and cloud sync; Foldcade does not back up Android saves to RomM.
