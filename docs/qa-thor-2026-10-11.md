# Thor QA fix verification — 11 October 2026

AYN Thor, Android 13; top display 1920 × 1080, bottom display 1240 × 1080, both at 120 Hz. Debug and non-debuggable release builds used the isolated application ID `app.foldcade.qapass`, signed for that test identity. Existing Foldcade installs, source files, and emulator settings were preserved. The implementation is based on `2357c99`.

## Findings addressed

- **QA-01, secondary Home:** the companion activity uses a supported `singleTop` launch mode. Explicit launches reuse their task, and activity registration retires an older Home task on the same display. System Home recalls Foldcade on either display. Role transitions, repeated Home presses, and repeated explicit companion launches retain one surface per display.
- **QA-02, token validation:** rejected tokens and unreachable servers show distinct errors. Validation shows “Checking token…”, blocks duplicate submissions, and discards results from a closed or edited form. Both default and additional-server setup use the same path. Device checks exercised invalid-token refusal and the loading/connection-error states; the stored valid token remained usable.
- **QA-03, setup controls:** forms show Confirm/Back rather than game launch hints. Grid focus is suppressed while setup is open. Verified on the two displays during token setup.
- **QA-04, launch cancellation:** both activities share a cancellable pending launch. B and the shoulder-menu route stop transfer work and invalidate late results; the footer exposes “Cancel download”. A cross-display B check stopped at 34,311,691 bytes. On the integrated build, L1 stopped an active Digimon transfer at 123,722,732 bytes; sizes remained unchanged at +3 and +6 seconds, with no completed ROM, verification marker, or late emulator launch.
- **QA-05, offline/reconnect:** a durable, server-scoped catalog restores titles, platform metadata, complete listings, and launch information after process death. Bounded artwork caches retain downloaded images. Tetris DS restored its title, cover, and hero artwork after a release cold start with Wi-Fi off, then launched its verified ROM in melonDS and rendered the game menu. Removing only the test catalog produced the Game unavailable dialog instead of StandIn. Enabling Wi-Fi restored the title and artwork in the same process (PID 7719), rebuilding 66 platforms, 32 ROM records, and five complete listings.
- **QA-06, focus performance:** animated state is read in drawing/layers where possible, cursor travel uses layer translation, and large hero marks are rasterized off main into an 8 MiB cache. The upstream keyed artwork/glide behavior is retained. See the controlled comparison below.
